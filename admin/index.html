Sign in and edit the website ↗

Your first time signing in?

  1. Sign in to Pages CMS with the GitHub account that owns the Shan-DUK website repository.
  2. When asked, let Pages CMS access the shan-duk.github.io website repository.
  3. Open the numbered sections: 1. Music shop, 2. Upcoming shows, or 3. Website info.
  4. Save your change. The live site will refresh after it publishes.

Keep your sign-in safe: use the Pages CMS sign-in button. Never type or send your GitHub password to anyone.
